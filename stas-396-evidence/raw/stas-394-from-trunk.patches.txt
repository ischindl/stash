Subject: [PATCH] fix(STAS-394): compose fix titles idempotently and record fix
 ancestry in lineage

A composed fix title was the raw material for the next composition, so each
generation added one more leading "Fix: " layer onto the same words. One
lineage family on a real board reached three through eight layers, and the
board clamps a card label at 80 characters.

packages/core/src/tasks/fix-title.ts now owns the prefix and exposes
composeFixTitle, which strips any leading layers before it prefixes, so
composing twice is the same as composing once. All four composing call sites
route through it: the generated fix feature title in async-mission-store.ts
(the live path), its deprecated synchronous twin in mission-store.ts,
formatRemediationStepName, and the fix-step name in the human merge approval
boundary. A subject carrying no prefix composes byte-identically to before.

Ancestry leaves the label. triageFeature now writes the parent card of a
generated fix feature into the card's existing source.sourceParentTaskId
lineage field, derived from generatedFromFeatureId, which this creation path
left empty while other paths already populate it. No new column, no migration,
no new SourceType.

The test drives the real createGeneratedFixFeature and triageFeature rather
than the helper. It failed at base 1d4bcc618 with only the test present (seven
assertions on the extra layer and the missing lineage link) and passes here;
the test ships in this commit so no commit on this branch is red.

Refs: STAS-394 (STAS-296/352/354/355/356/357 lineage family)

+/**
+ * The engine's fix-title prefix and the one rule for putting it on a title.
+ *
+ * `createGeneratedFixFeature` composes a remediation feature's title from its parent feature's
+ * title, and `triageFeature` copies that feature title verbatim onto the board card, so this
+ * string reaches operators. It is exported from here alone; every site that wants a `Fix: ` title
+ * calls {@link composeFixTitle} instead of re-typing the literal.
+ */
+export const FIX_TITLE_PREFIX = "Fix: " as const;
+
+/**
+ * Compose the title of fix work about `subject`, carrying exactly one prefix layer.
+ *
+ * The leading layers are stripped before the prefix is applied, so a subject that already carries
+ * it comes back unchanged and composing twice is the same as composing once. That normalization is
+ * the whole point: a composed title used to become the next generation's raw material, so each
+ * generation stacked one more layer onto the same words. One lineage family on one board reached
+ * three through eight leading layers, and the board clamps a card label at 80 characters.
+ *
+ * Ancestry belongs to the lineage fields the store already has — `generatedFromFeatureId` for a
+ * feature and `sourceParentTaskId` for the card it triages into — never to the label.
+ */
+export function composeFixTitle(subject: string): string {
+  let base = subject;
+  while (base.startsWith(FIX_TITLE_PREFIX)) {
+    base = base.slice(FIX_TITLE_PREFIX.length);
+  }
+  return `${FIX_TITLE_PREFIX}${base}`;
+}
