A personal curator's wall-cut pass now prices its own reading, so the reading allowance stops
shrinking for a reason that has nothing to do with reading.

Two rows from the founder lane, written the evening its first calibration rows ever appeared,
say what was wrong:

    calibration_key | characters | seconds | s/char  |   read allowance next
    local:internal  |       4 750 |   930  | 0,19579 |   2 911
    local:internal  |       2 911 |   930  | 0,31948 |   ~1 784

Both rows filed the whole run's wall over the reading allowance the run had been handed. But a
personal run is two model turns inside one wall — a digest reads, then the wiki writer writes —
and the writer is what the run dies on (measured the same evening on the same lane: 45 seconds
of digest over 1 735 characters against roughly 730 seconds of writer), while the number those
rows were feeding is spent by `personal_budget_of` on the reading alone, after it had already
subtracted a fixed 270-second write share. The writer was being counted twice, and because the
writer is not what a smaller reading allowance shortens, each cut row made the next allowance
smaller against an unchanged wall: 4 750, then 2 911, then about 1 784.

The cut row now files the same allowance over the seconds the reading phase itself spent, read
back out of the events that phase already wrote — its prompt is that session's first row and its
report the last, and the run's close is excluded by name because the close arrives only when the
whole run ends. On the founder lane that is about 0,026 seconds per character rather than
0,19579, and the reading allowance answers its ceiling, 8 192 characters, and stops there.

Read that plainly: the reading was never the binding cost, and the log will now say so with a
number that names the thing the knob controls. The wall still cuts a run whose writer cannot
finish inside it, and the writer is STAS-497's subject, not this change's. A pass that committed
still files the characters it read over the run's own wall, exactly as it did, by the operator's
direction — that row is a mixed figure on purpose and this change leaves it where it stands.
What the run never read at all is no longer priced at all: a cut run whose reading session wrote
no events files nothing and says so once, rather than inventing a number.
