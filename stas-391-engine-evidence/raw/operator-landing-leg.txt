- `patch` — GNU patch, the fuzz-tolerant applicator an operator would use by hand.
- `git apply` — git's own strict applicator, the one a `git am` or a scripted
  landing uses. rc=1 with a 'patch failed' line means it refuses the diff as-is.
- `merge-file` — what a real `git merge` resolves to. rc=0 with zero conflict
  blocks merges silently; rc=2 with N blocks means a human resolves N regions.

`merge-file` numbers behind these verdicts are in raw/base-witness.txt, which runs
them against the same blobs this file names.
